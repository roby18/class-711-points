# 711 班级积分表

> 广铁一中铁英学校 · 初一 11 班 · 班级加减分积分管理系统

## 📋 简介

一个纯静态 HTML 网页应用，用于班级日常加减分积分管理。**双击 `index.html` 即可使用**，无需安装任何软件或联网（除 Google Fonts 外）。

适用于班主任和学委共同操作，支持积分管理、拍卖兑奖、班级评选、学生分组等功能。

---

## ✨ 功能一览

| 模块 | 说明 |
|---|---|
| **➕ 加分 / ➖ 减分** | 按出勤、学习、卫生、纪律、文明礼仪五大分类加减分，默认 ±1 分可手动调整 |
| **🔐 密码保护** | 可开启密码验证，进入加减分面板需输入老师或学委密码 |
| **🎁 积分拍卖** | 发布奖品，学生用积分竞拍，自动记录获奖者 |
| **🏅 班级评选** | 每周评选奖项，历史获奖记录支持单独删除或一键清空 |
| **👥 学生分组** | 创建小组，支持多选学生一键批量加入 |
| **⚙️ 设置管理** | 添加/删除学生、修改密码、导入/导出 JSON 数据 |
| **📋 数据持久化** | 全部数据存储在浏览器 localStorage，关闭重开不丢失 |
| **💾 JSON 备份** | 一键导出全班数据为 JSON 文件，支持导入合并（不覆盖已有数据） |

---

## 🚀 使用方法

### 本地使用
1. 双击 `index.html`，浏览器自动打开
2. 看到初始欢迎界面，点击「开始使用」
3. 进入主页后点击四大卡片进入对应功能

### 在线部署
支持部署到 EdgeOne Pages / GitHub Pages 等静态托管平台。

## 🔧 技术说明

- 纯 HTML + CSS + Vanilla JS，零构建工具
- 数据存储：`localStorage`（浏览器本地存储）
- 唯一外部依赖：Google Fonts（Fredoka / Caveat / Noto Sans SC）
- 离线可用（字体加载后缓存）

### 数据安全
- 导入 JSON 时采用 **merge 策略**，不会覆盖已有学生数据
- `localStorage` 为权威数据源
- 删除操作均有二次确认弹窗
- 预填充名单仅在首次空数据时触发，不会覆盖已存在的数据
